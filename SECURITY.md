# Security Policy / セキュリティポリシー

## English

### Supported versions

Security fixes are provided for the latest released version only.

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older releases | No |

### Reporting a vulnerability

Do not report security vulnerabilities through a public GitHub Issue, Discussion,
or Pull Request. Use GitHub's
[private vulnerability reporting form](https://github.com/murata-sensor/soil-sensor-samples-python/security/advisories/new)
instead.

Include the following information when possible:

- A description of the vulnerability and its potential impact
- The affected version, sensor product, and firmware version
- The operating system, Python version, serial adapter, and command used
- Minimal reproduction steps or a proof of concept
- Suggested mitigation, if known

Remove credentials, tokens, sensor serial numbers, customer data, and other
confidential information from all reports and attachments. Do not test against
systems or devices that you do not own or have permission to test.

If the private reporting form is unavailable, do not disclose the vulnerability
in a public issue. Contact the maintainers at
[murata_sensor@murata.com](mailto:murata_sensor@murata.com) instead. Do not
include vulnerability details or other sensitive information in the initial
email; first ask for a private channel for the report.

For general defects, usage questions, and feature requests that do not involve a
security vulnerability, use
[GitHub Issues](https://github.com/murata-sensor/soil-sensor-samples-python/issues).

## 日本語

### サポート対象version

Security修正は、最新のrelease versionのみを対象とします。

| Version | サポート |
|---------|----------|
| 最新release | 対象 |
| 過去のrelease | 対象外 |

### 脆弱性の報告

Security上の脆弱性を、公開GitHub Issue、Discussion、Pull Requestへ投稿しないで
ください。GitHubの
[非公開脆弱性報告フォーム](https://github.com/murata-sensor/soil-sensor-samples-python/security/advisories/new)
を使用してください。

可能な範囲で、以下の情報を記載してください。

- 脆弱性の内容と想定される影響
- 対象version、センサ品番、firmware version
- OS、Python version、serial変換器、実行したcommand
- 最小限の再現手順またはproof of concept
- 判明している場合は、回避策または修正案

報告および添付ファイルから、認証情報、token、センサのserial number、顧客情報、
その他の機密情報を削除してください。所有していない、または試験許可を得ていない
systemやdeviceに対して検証を行わないでください。

非公開報告フォームが利用できない場合も、脆弱性を公開Issueへ投稿しないでください。
代わりに [murata_sensor@murata.com](mailto:murata_sensor@murata.com) へ連絡して
ください。最初のメールには脆弱性の詳細やその他の機密情報を記載せず、非公開で
報告できる方法をお問い合わせください。

Security上の脆弱性ではない一般的な不具合、ご質問、機能要望は、
[GitHub Issues](https://github.com/murata-sensor/soil-sensor-samples-python/issues)
を使用してください。
