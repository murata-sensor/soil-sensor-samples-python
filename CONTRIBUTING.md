# Contributing / コントリビューション

## English

Thank you for your interest in this project. Bug reports, questions, and feature
requests are welcome through [GitHub Issues](https://github.com/murata-sensor/soil-sensor-samples-python/issues).
For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not open
a public issue.

Before opening an issue:

- Search existing issues to avoid duplicates.
- Include the sensor product, firmware version, operating system, Python version,
  serial adapter, command used, and the smallest reproducible example.
- Remove credentials, tokens, serial numbers, customer data, and other confidential
  information from logs and attachments.

This repository does not currently accept external pull requests. Proposed code
changes may be described in an issue for consideration.

## 日本語

不具合報告、ご質問、機能要望は
[GitHub Issues](https://github.com/murata-sensor/soil-sensor-samples-python/issues)
で受け付けています。
Security上の脆弱性は[SECURITY.md](SECURITY.md)に従い、公開Issueへ投稿しないで
ください。

Issueを作成する前に、以下をご確認ください。

- 既存Issueを検索し、同じ内容がないことを確認してください。
- センサ品番、firmware version、OS、Python version、serial変換器、実行した
  command、および最小限の再現手順を記載してください。
- logや添付ファイルから、認証情報、token、serial number、顧客情報、その他の
  機密情報を削除してください。

現在、外部からのPull Requestは受け付けていません。コード変更のご提案は、
Issueに内容を記載してください。
