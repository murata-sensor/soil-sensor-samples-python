# SLT5006 / SLT5005 — Murata binary protocol

SLT5005 uses the same firmware and protocol as SLT5006; the only difference is
the electrical interface (SLT5005 = RS-232C, SLT5006 = UART/TTL).

## Serial settings (PC side)

| Setting | Value |
|---------|-------|
| Baud rate | 9600 |
| Data bits | 8 |
| Parity | None |
| Stop bits | 1 |

## Frame format

Read request (5 bytes):

```
| 0x01 (Read) | Address (1B) | Size (1B) | CRC_H (1B) | CRC_L (1B) |
```

Read response:

```
| 0x01 | Address | Size | Data[0..Size-1] | CRC_H | CRC_L |
```

Write request:

```
| 0x02 (Write) | Address (1B) | Size (1B) | Data[..] | CRC_H | CRC_L |
```

Error response:

```
| FunctionCode | ErrorCode | CRC_H | CRC_L |
```

The error response is exactly 4 bytes. Bit 7 is set in `FunctionCode`
(`request FunctionCode | 0x80`); `0x80` is not a separate byte. The library
validates the function code and CRC before raising `SensorDeviceError` with the
sensor error code.

- CRC is CRC-16/MODBUS (see [README.md](README.md)); high byte first.
- Multi-byte measurement values are little-endian (low byte at the lower address).

## Reading a measurement (typical flow)

1. Trigger a measurement by writing the sensor-control register.
2. Poll the sensor-state register until the "measurement done" flag is set.
3. Read the measurement registers and apply the scaling for each value.

Example scalings:

- Temperature: signed value x 0.0625 [degC]

> The full register map (addresses, scalings, and non-public registers) is
> defined in the SLT5006 datasheet. Only read the customer-public registers.
