# SLT5009 — MODBUS RTU (RS-485)

## Serial settings (PC side)

| Setting | Value |
|---------|-------|
| Baud rate | 9600 |
| Data bits | 8 |
| Parity | None |
| Stop bits | 1 |
| Interface | RS-485 (half-duplex) |

## Frame format (MODBUS RTU)

Read Holding Registers (function code `0x03`):

```
| Slave (1B) | 0x03 | StartAddr_H | StartAddr_L | NumReg_H | NumReg_L | CRC_L | CRC_H |
```

Write Multiple Registers (function code `0x10`):

```
| Slave (1B) | 0x10 | StartAddr_H | StartAddr_L | NumReg_H | NumReg_L | ByteCount | Data[..] | CRC_L | CRC_H |
```

- Register addresses and counts are **big-endian** on the wire (MODBUS standard).
- CRC is CRC-16/MODBUS; low byte first.

## Register map (public)

The datasheet map is **byte-addressed**: a 16-bit value occupies consecutive
`_U` (upper) and `_L` (lower) byte addresses. In the MODBUS request, however,
`NumReg` counts complete 16-bit values. Reading one U/L pair therefore uses
`NumReg=1` and returns two data bytes; do not request `NumReg=2` for one pair.

| Addr | R/W | Register | Notes |
|------|-----|----------|-------|
| 0x0000 / 0x0001 | R | MAJOR_VERSION U/L | |
| 0x0002 / 0x0003 | R | MINOR_VERSION U/L | |
| 0x0004 / 0x0005 | R | REVISION U/L | |
| 0x0006-0x0009 | R | SERIAL_NO UU/UL/LU/LL | 32-bit |
| 0x000A / 0x000B | RW | SNSR_CTRL U/L | Start measurement: set bit0 (MEASRUN) of 0x000B |
| 0x000C / 0x000D | R | SNSR_STATE U/L | bit0 (MEASDONE) of 0x000D indicates completion |
| 0x000E / 0x000F | R | DDS U/L | 12-bit |
| 0x0010 / 0x0011 | R | ADC_EC U/L | 12-bit |
| 0x0012 / 0x0013 | R | ADC_PERMITTIVITY U/L | 12-bit |
| 0x0014 / 0x0015 | R | ADC_BATTERY U/L | 12-bit |
| 0x0016 / 0x0017 | R | TEMP U/L | SIGN + 11-bit, x 0.0625 degC |
| 0x0018 / 0x0019 | R | EC_BULK U/L | 16-bit |
| 0x001A / 0x001B | R | VWC_ROCK U/L | 10-bit |
| 0x001C / 0x001D | R | VWC U/L | 10-bit |
| 0x001E / 0x001F | R | VWC_COCO U/L | 10-bit |
| 0x0020 / 0x0021 | R | Reserved | |
| 0x0022 / 0x0023 | R | EC_PORE U/L | 16-bit |
| 0x0024 / 0x0025 | R | EC_PORE_COCO U/L | 16-bit |
| 0x0026 / 0x0027 | RW | SENSOR_NUMBER U/L | ADDRESS[4:0] in 0x0027 |

Source: SLT5009 datasheet, section "Register map SLT5009".

Valid configured slave (sensor) numbers are **1-31**. Address `0` cannot be
stored as a sensor number, but MODBUS reserves it for broadcast requests.
`read_address()` reads the public SENSOR_NUMBER register; `set_address()`
checks a live readback after changing it. The write acknowledgement still uses
the **old** slave number, and only subsequent requests use the new one.
Before changing an address, confirm that the requested number is unused while
all bus devices are powered, or connect only the target sensor. The
`examples/set_address.py` script performs this probe and refuses to write on a
response or an invalid response; only a timeout is treated as unused.

## Typical flow

1. Write `0x0001` to start a measurement (SNSR_CTRL, bit0 of 0x000B).
2. Poll SNSR_STATE (0x000C/0x000D) until MEASDONE is set.
3. Read the desired measurement registers and combine U/L, then apply scaling.

## Simultaneous measurement start (broadcast)

For two or more SLT5009s on one physical bus, the library can broadcast only
the fixed, safe operation "write `SNSR_CTRL=MEASRUN`":

```python
from murata_soil_sensor import read_broadcast_measurement

measurements = read_broadcast_measurement(sensors, transport)
```

The convenience function is fail-fast. A logger that must keep results from
responsive sensors can separate start and readout:

```python
from murata_soil_sensor import start_broadcast_measurement

errors = start_broadcast_measurement(
    sensors, transport, continue_on_error=True
)
for sensor in sensors:
    if sensor.slave in errors:
        print(sensor.slave, errors[sensor.slave])
        continue
    try:
        print(sensor.slave, sensor.read_data(transport))
    except Exception as exc:
        print(sensor.slave, exc)
```

`continuous_log.py` and `gui_monitor.py` use this tolerant form when
`--broadcast-start` is enabled, so one non-responsive listed sensor does not
discard data from the others.

The exact request is `00 10 00 0A 00 01 02 00 01 6A AA`. No sensor
acknowledges a MODBUS broadcast. Every SLT5009 physically connected to the bus
starts measuring, including devices not present in the Python `sensors` list.
For that reason the examples use it only with explicit `--broadcast-start`;
generic broadcast writes and broadcast address changes are not exposed.

Confirm that the power supply can support all sensors' measurement-current
peak before enabling this option. The implementation also uses a conservative
10 ms silent interval between SLT5009 frames for half-duplex turn-around.

After changing an address, turn the sensor power source off without connecting
or disconnecting energized wiring. Wait a few seconds, restore power, and run
`examples/verify_address.py` with the expected serial number to confirm
non-volatile retention and sensor identity.

MODBUS exception responses are CRC-, slave-, and function-checked before the
library raises `SensorDeviceError`. Normal responses are read by their declared
length and validated for slave, function, byte count, and write echo.
